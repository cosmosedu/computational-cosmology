# Astrostatistics & Computational Cosmology Journey

> A public learning repository documenting my transition from undergraduate physics to computational cosmology through Python, mathematics, statistics, and data science.

---

## About This Repository

This repository contains my complete learning journey toward becoming a computational cosmologist.

Instead of uploading only finished projects, I document every stage of learning:

* Daily coding exercises
* Weekly mini-projects
* Notes and observations
* Mistakes and corrections
* Physics-oriented programming practice
* Git and GitHub workflow

The goal is to build strong computational foundations before moving into real cosmological data analysis.
